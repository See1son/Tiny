# Tiny

Tiny 是 Windows 托盘额度工具，用两行数字显示 Codex 剩余额度。

## 开始使用

1. 本机安装 Codex，并使用 ChatGPT 账号登录。
2. 解压便携包，将文件夹放在固定位置。
3. 双击 `Tiny.exe`，程序会在系统托盘中显示数字图标。

如果任务栏上找不到图标，点击托盘的展开箭头；也可以将图标拖到可见区域。

## 查看额度

图标为黑底白字，数字省略百分号：

- 上行：week 剩余额度。
- 下行：5 h 剩余额度。
- `...`：该项暂时没有可用数据。

启动后立即读取额度，此后每 60 秒自动更新。

将鼠标停在图标上，可以查看各周期的重置时间和可用重置次数，例如：

```text
week：10-20 16:57
5 h：10-15 03:16
可用重置：2 次
```

时间使用 Windows 当前本地时区。“可用重置”只显示剩余次数，Tiny 不会执行重置。

## 右键菜单

- **开机启动**：点击切换，勾选后会在当前用户登录 Windows 时自动运行。默认关闭。
- **退出**：关闭 Tiny。

移动程序前，先取消开机启动，移动后再重新勾选；删除程序前也请先取消开机启动。

## 读取异常

如果额度持续显示 `...`，将鼠标停在图标上查看错误提示，并检查 Codex 登录状态和网络连接。
